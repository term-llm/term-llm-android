# Supplemental owned-emulator journeys

Never target a production device/node. Fixture accounts/config/keys stay outside source.

- Exactly-once: grant app/source tools and page opt-in, ask a real model for one media_add, compare debug_dispatch_count from two media_now_playing probes; expected delta2. Verify one queue item.
- Process death: run `python3 testing/media_fixture.py --port18999 --delay .5 --log "$TEST_SECRETS_DIR/ranges.jsonl"`, add/download its WAV, choose Music/query, Home, wait until activity is STOPPED with saved state, then own-UID SIGKILL. Reopen without force-stop/reinstall. Check changedPID, restored query, Range+If-Range, exact bytes and no auth header on public fixture.
- Native timeout: record original `device_config get activity_manager data_sync_fgs_timeout_duration`; enable `am compat enable --no-kill FGS_INTRODUCE_TIME_LIMITS com.termllm.app`; set budget5000, start a confirmed real enrolled stream while foreground, Home, wait12s. Require service before/nonexistent after and samePID. Return foreground; RESTORE original device_config and reset ONLY this compat override in a trap. Never clear all device settings.
- Network: Home with active HTTPS stream, airplane-mode enable8s/disable, no app return, send only to a test node, wait up to90s watchdog+backoff for native delivery. Compare PIDs and tap via actual system notification.
- Noisy: ordinary shell cannot emit the protected action. On a DISPOSABLE userdebug emulator only, temporarily `adb root`, keep app playing a QA WAV, send `am broadcast -a android.media.AUDIO_BECOMING_NOISY`, observe pause, `adb unroot` and restore owned reverse mappings. Never root a physical device for this recipe.
- UI: pair screenshots with UIAutomator XML and assert activity/window packages. System permission/notification shade windows require their own package/window guard. Prefer tab-* and push-relay-* resource IDs, semantic labels, or actual element bounds. Preserve and restore font_scale, wm overrides, theme, compat/device_config. Actual split screen uses the launcher app-icon menu; a narrow wm viewport alone is NOT split-screen proof.
- Release: use isolated .benchmark package for permission/profile/startup checks. The external-UID ControllerTrustTest additionally requires the owned DEBUG main fixture installed, and fails on missing package, sameUID, unexpected connect or timeout.
